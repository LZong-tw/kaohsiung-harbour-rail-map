# 第 1–35 輪的比對圖

這些圖原本只留在工作環境的暫存區（`/tmp`），沒有進 repo。第 36 輪使用者指正：「你對話中的截圖切圖比對圖明明就很多，你卻一張都沒存進 GIT 裡」「過往的圖也要放進 git，不然太浪費了」，所以用 `pipeline/archive_figs.py` 一次收進來，共 626 張。

- `rNN/`：依建立時間對到的輪次（以各輪 commit 時間為界；第 19 輪以前的都歸在 `r19/`）。第 32、33 輪由另一個 agent 在別的環境做，這裡沒有那兩輪的圖。
- `MANIFEST.tsv`：每張圖的檔名、內容、舊檔名、當時的暫存檔、輪次、原尺寸、底圖。
- 都轉成 JPEG（長邊最多 1600 px），原始尺寸記在清單裡。
- **檔名**：「底圖或圖的種類_地點_內容__舊檔名」，例如 `1945美軍圖_高雄港站站場_疊線__gk45o.jpg`。第 36 輪由我逐張看縮圖後命名（`pipeline/rename_past_figs.py`，新舊對照在 `檔名對照.tsv`）；原本沿用暫存檔名（`a.jpg`、`c55.jpg`），看不出內容。
  - 命名是看縮圖做的：底圖種類和大略位置可靠，「疊線」「放大」這類描述也可靠；地點寫的是圖上認得出的地名，細部沒有逐張放大核對。
  - 檔名開頭是「空白圖」的 25 張是當時抓到的空白圖磚（該圖層在那個位置或縮放層級沒有資料），留作「查過、沒有」的紀錄。
  - 兩個底線後面是舊檔名，用來對回 `WORKLOG.md` 對應輪次當時的說法。
