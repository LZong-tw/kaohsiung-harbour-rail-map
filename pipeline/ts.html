中央研究院臺灣百年歷史地圖 WMTS 服務

服務網址為：https://gis.sinica.edu.tw/tileserver/wmts

語法(OGC WMTS服務)
https://gis.sinica.edu.tw/tileserver/wmts?SERVICE=WMTS&REQUEST=GetTile&VERSION=1.0.0&LAYER={Layer_ID}&STYLE=_null&TILEMATRIXSET= GoogleMapsCompatible &TILEMATRIX={z}&TILEROW={y}&TILECOL={x}&FORMAT=image/jpeg

案例：

  • 日治二萬分之一台灣堡圖(明治版)
    https://gis.sinica.edu.tw/tileserver/wmts?SERVICE=WMTS&REQUEST=GetTile&VERSION=1.0.0&LAYER=JM20K_1904&TILEMATRIXSET=GoogleMapsCompatible&TILEMATRIX=12&TILEROW=1753&TILECOL=3430&FORMAT=image/jpeg
  • 日治五萬分之一地形圖(陸地測量部)
    https:/gis.sinica.edu.tw/tileserver/wmts?SERVICE=WMTS&REQUEST=GetTile&VERSION=1.0.0&LAYER=JM50K_1920&TILEMATRIXSET=GoogleMapsCompatible&TILEMATRIX=12&TILEROW=1753&TILECOL=3430&FORMAT=image/png

語法(RESTful API)
https://gis.sinica.edu.tw/tileserver/file-exists.php?img={Layer_ID}-{Image_Format}-{z}-{x}-{y}

案例：

  • 日治二萬分之一台灣堡圖(明治版)

    https://gis.sinica.edu.tw/tileserver/file-exists.php?img=JM50K_1920-png-12-3430-1753

GIS應用軟體介接：

  • QuantumGIS Desktop 2.0 : open with Layer->Add WMS layer
    https://gis.rchss.sinica.edu.tw/qgis/archives/2569/
  • ESRI ArcGIS Desktop 10.1+ : native WMTS implementation supported
    https://desktop.arcgis.com/en/desktop/latest/manage-data/using-arccatalog/connecting-to-gis-servers.htm
  • ESRI ArcGIS Online : MODIFY MAP -> Add Layer from Web -> choose 'A WMTS OGC Web Service'
    https://www.arcgis.com/home/webmap/viewer.html
  • ArcBruTiles plugin for ArcGIS 9.3+ : via TMS endpoint
    https://arcbrutile.codeplex.com
  • OpenLayers WMTS Layer - including parsing GetCapabilities
    https://www.openlayers.org
  • GAIA - native WMTS (issues with 3857 to be fixed)
    https://www.thecarbonproject.com/gaia.php
  • OruxMaps(Android APP) : update oruxmaps/mapfiles/onlinemapsources.xml
    https://gis.sinica.edu.tw/tileserver/onlinemapsources.xml
  • Mobile Atlas Creator(MOBAC) : add "Custom maps" XML files into the mapsources directory
    https://gis.sinica.edu.tw/tileserver/mobac.zip
  • Viking GPS data editor and analyzer : replace "Custom maps" XML files into /.viking/maps.xml
    https://gis.sinica.edu.tw/tileserver/viking.zip
  • SuperGIS Desktop 3.2 : with OGC Service Add-on
    https://www.supergeo.com.tw/P_OGCAddon.asp
  • Locus(Android APP) : copy xml file to Locus\mapsOnline\custom folder
    https://gis.sinica.edu.tw/tileserver/Locus_OnlineMaps.zip
