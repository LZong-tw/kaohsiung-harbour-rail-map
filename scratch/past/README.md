# 第 1–35 輪的比對圖

這些圖原本只留在工作環境的暫存區（`/tmp`），沒有進 repo。第 36 輪使用者指正：「你對話中的截圖切圖比對圖明明就很多，你卻一張都沒存進 GIT 裡」「過往的圖也要放進 git，不然太浪費了」，所以用 `pipeline/archive_figs.py` 一次收進來，共 626 張。

- `rNN/`：依建立時間對到的輪次（以各輪 commit 時間為界；第 19 輪以前的都歸在 `r19/`）。第 32、33 輪由另一個 agent 在別的環境做，這裡沒有那兩輪的圖。
- `MANIFEST.tsv`：每張圖的原檔名、輪次、原尺寸、來源類別。來源是依檔名推定的，個別圖可能是同一類裡的其他圖資，判讀時以圖本身為準。
- 都轉成 JPEG（長邊最多 1600 px），原始尺寸記在清單裡。
- 檔名沿用原本的暫存檔名，大多沒有說明文字；當時的判讀與結論記在 `WORKLOG.md` 對應的輪次。
